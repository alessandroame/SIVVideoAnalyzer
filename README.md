# SIV Video Analyzer

Software stand-alone desktop per l'analisi, catalogazione, montaggio e capitoli per video SIV parapendio.

## Avvio rapido
`ash
.\venv\Scripts\activate
python main.py
`

## Prossima Lavorazione: Interfaccia a Wizard Guidato (3 Step)
- Step 1: Selezione cartella video, lista piloti e cartella destinazione (con memoria persistente).
- Step 2: Tabella a schermo intero per approvazione e riassegnazione video.
- Step 3: Hub finale con selettore del pilota, montato dedicato, player integrato e capitoli.
